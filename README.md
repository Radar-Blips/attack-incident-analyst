# attack-incident-analyst
This Project is designed to use CLaude API and agents to act as incident handlers for investigation purposes. Built using the public ATT&CK-labelled datasets from Splunk (attack_data).
Output from raw attack logs (xml) to easy to understand incident reports. 
How it's tested: Hand labelled eval cases with tiered scoring and a rubric to compare with the AI models output.
Status: early testing with initial test case created from the attack data. Agent output not yet commited to Repo.
Scoring criteria will be shown at a later day along with comparison of model performance at different tiers.
